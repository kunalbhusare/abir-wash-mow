# Abir's Wash & Mow

Single-page static site (HTML + CSS, no JS, no trackers, no forms). Source is in `site/`.

## Placeholders to swap (all in `site/index.html`)
1. Parent phone: `tel:+61400000000` (search `PLACEHOLDER`) -> real mobile in international format.
2. Parent email: `mailto:parent@example.com` -> real parent email.
3. Car wash price: `$[PRICE]` (first one in "Simple pricing").
4. Lawn mow price: `$[PRICE]` (second one). Then remove the "Placeholder" badge and edit the note.

## Safety rules
No surname, address, school, age or photos of Abir. All contact goes to a parent. No form. Keep it that way.
